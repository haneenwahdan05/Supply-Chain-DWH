# Supply Chain Data Warehouse & Power BI Dashboard

End-to-end Supply Chain analytics solution built with a SQL Server data warehouse (Bronze, Silver, and Gold layers) and an interactive 4-page Power BI dashboard.

## Project Structure
- `Bronze Layer.sql` — Raw data ingestion structure
- `Silver Layer.sql` — Cleaned and standardized tables
- `Gold Layer.sql` — Analytical dimensional and fact layer
- `Sprint 4 Dashboard.pbix` — Interactive Power BI report

## Tools Used
- **SQL Server** (Medallion Architecture / Data Warehouse modeling)
- **Power BI** (Data visualization and reporting)
